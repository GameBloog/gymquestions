# SPEC - Onboarding Guiado

Implementar onboarding guiado para primeiro acesso de professores e alunos.

O onboarding deve usar spotlight, máscara, tooltip contextual, navegação entre passos e progresso visual. A fonte de verdade do estado é o backend. O usuário pode concluir, pular e reiniciar o fluxo.

Perfis cobertos:
- Professor
- Aluno

Fora do escopo inicial:
- Onboarding para Admin
- Tracking analítico granular
- Recalcular ou criar dados funcionais automaticamente
