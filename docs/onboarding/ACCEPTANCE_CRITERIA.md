# ACCEPTANCE CRITERIA - Onboarding Guiado

- Usuário professor ou aluno sem onboarding concluído recebe `shouldStart=true`.
- Onboarding não inicia quando há aceite legal pendente.
- Progresso, conclusão, pular e reinício são persistidos no backend.
- Checklist pós-onboarding é calculado no backend.
- Checklist desaparece quando todos os itens estiverem concluídos.
- Fluxo funciona em desktop, tablet e mobile sem bloquear uso essencial.
- Ajuda permite refazer onboarding e consultar guia rápido.
- Admin não recebe fluxo de onboarding nesta versão.
